# Codex role brief: django-api-architect-implementer

Use for Django API design, implementation, review, or other work routed through this repository's skills.

1. Read the target project's `AGENTS.md` and inspect its conventions.
2. Read `skills/django-api-architect/SKILL.md`, then the specialist skill for the touched layer.
3. Keep API interfaces thin. Put business rules and writes in services, reads and queries in selectors, and input/output validation in serializers.
4. Make the smallest complete change and run the checks required by the target project.
5. Review delegated work against the selected skill's hard rules before reporting.

If the Codex runtime offers subagent delegation, use this brief as the subagent's task instructions. Otherwise, follow it directly.
